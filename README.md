## 📌 Loyiha haqida

Bu — mening shaxsiy **portfolio saytim** bo'lib, o'zim haqimdagi ma'lumotlar, ko'nikmalarim va loyihalarimni bir joyda taqdim etish maqsadida yaratilmoqda. Hozirda loyiha **boshlang'ich bosqichda** — sayt tuzilmasi (navigatsiya) tayyorlangan, kontent qismi bosqichma-bosqich to'ldirib boriladi.

## 🧭 Sayt tuzilmasi

Hozirgi holatda saytda quyidagi navigatsiya bo'limlari mavjud:

| Bo'lim | Tavsif |
|---|---|
| 🏠 **Home** | Bosh sahifa |
| 👤 **About** | Men haqimda ma'lumot |
| ✉️ **Contact** | Bog'lanish uchun ma'lumotlar |

> 🔧 Loyiha faol rivojlantirilmoqda — yangi bo'limlar (Skills, Projects) tez orada qo'shiladi.
